# فريق الموقع (website-team)

فريق مراجعة بيشتغل بالخلفية على موقع جاهز. لجنة من ٤ أعضاء (المشجّع، الناقد، الفاحص التقني، الرئيس) بتراجع الموقع، وكل إصلاح بيتحقق منه باختبارات متصفح حقيقية. أي إصلاح ما بيحسّن، أو بيكسر شي ثاني، بيترفض تلقائياً. وبالآخر بيعطيك ملخص قصير جداً، وتقرير صادق بملف.

## كيف تستخدمه
اشتغل مع Claude على موقعك بطريقته العادية. لما تخلص، قله «خلي فريق الموقع يراجع الموقع».
- الفريق بيشتغل بهدوء: بيفحص، وبتراجع اللجنة، وبيصلّح بس اللي بيثبت بالاختبار.
- بالآخر بيعطيك ملخص من ٥–٦ أسطر، والتفاصيل كلها بملف `website-team/REPORT.md`.
- ما بيسأل أسئلة وما بيعرض اتجاهات تصميم.
- ما بيغيّر المحتوى (نصوص، أسعار، أرقام) من حاله. هدول بيظهروا كاقتراحات.
- ما بيشتغل إلا إذا طلبته بالاسم، وما بيأثر على باقي محادثاتك.

## المكوّنات
- **Skill `website-team`:** المنسّق، وبيشغّل الدورة كاملة.
- **٤ وكلاء:** `site-advocate` و`design-critic` و`qa-inspector` و`committee-chair`.
- **سكربتات** (بدون ذكاء اصطناعي ولا توكن):
  - `run_tests.py`: اختبارات متصفح حقيقية لأي موقع ثابت.
  - `verify_fix.py`: حلقة الإصلاح. بتقبل التعديل بس إذا أصلح هدفه بدون أي تراجع، وبتطبّق حداً أقصى للمحاولات وسجل قرارات.
  - `report.py`: حقائق التقرير من النتائج المسجّلة فقط.
  - `validate_committee.py`: بيتأكد إن تقارير اللجنة كاملة وكاتبها العضو نفسه، وإن خطة الرئيس متّسقة مع نتائج الاختبارات، وبياخد بصمة لكل تقرير.
  - `audit_project.py`: تدقيق آلي، بيعيد تشغيل الاختبارات، وبيعيد بناء كل نسخة من سجل القرارات، وبيتأكد إن ولا فحص انضعف.
  - `check_env.py` و`selftest.py` و`selftest_loop.py`: فحص البيئة، واختبار الاختبارات نفسها، واختبار قواعد حلقة الإصلاح.
- **فحوص سلوكية مخصّصة (scenarios):** اللجنة بتحوّل الشكوك لفحوص حقيقية، مثلاً «الطلب بسلة فارغة ممنوع». إذا فشل الفحص بتصير المشكلة مثبتة، والإصلاح بينقبل بس إذا خلّاه ينجح.

## المتطلبات
Python 3 وPlaywright وChromium:
`pip install playwright && python3 -m playwright install chromium`
ما في حاجة لمفتاح API.

## الحدود (بصراحة)
- مخصّص للمواقع الثابتة (HTML/CSS/JS). ما بيشغّل خوادم مثل Node أو PHP.
- **ما بيغطي:** الأداء (Lighthouse)، وتدقيق إمكانية الوصول الكامل، والأمان، والمتصفحات غير Chromium، والخادم الحقيقي، والنتائج التجارية. كل هدول بيظهروا بالتقرير بحالة «لم يُنفَّذ».
- الاختبارات معزولة عن الإنترنت، فالموارد الخارجية بتنحجب وبتظهر بالتقرير.

سجل التغييرات بملف `CHANGELOG.md`.
