# فريق الموقع (website-team)

سكل بيراجع موقع جاهز لما تطلبه بالاسم، بسرعة وباستهلاك قليل (حوالي دقيقة، ونفس استهلاك Claude العادي تقريباً).

## كيف تستخدمه
بعد ما يخلص Claude موقعك، قله:
- **«خلي فريق الموقع يراجع الموقع»** ← الوضع السريع (الافتراضي).
- **«خلي فريق الموقع الكامل يراجع الموقع»** ← اللجنة الكاملة (٤ شخصيات). أبطأ وبيصرف أضعاف، لمواقع كبيرة أو معقدة.

## الوضع السريع: شو بيعمل
1. **فحص بمتصفح حقيقي** (`scan.py`): أخطاء JavaScript، أزرار ما بتشتغل، فورمات بتعرض «تم الإرسال» وهي ما بتبعت شي، روابط مكسورة، نصوص بديلة للصور، تباين الألوان، تسميات الحقول، `lang` و`dir="rtl"`، `title`، الجوال، التمرير الأفقي. بيطبع كل مشكلة مع رقم السطر.
2. **Claude بيراجع الكود بنفسه** ويصلّح الأخطاء المنطقية اللي الفحص الآلي ما بيشوفها (حسابات غلط، فلاتر، روابط واتساب...).
3. **إعادة فحص** بتثبت شو انصلّح وشو انكسر، وبتعيد الملفات المكسورة من النسخة الاحتياطية.
4. **ملخص قصير** فيه بس الأرقام والقرارات اللي بدها منك.

الضمانات: ما بيغيّر نصوص ولا أسعار ولا أرقام تواصل، ما بيحذف روابط ولا أزرار ولا أقسام، وما بيخلي فورم يدّعي إنه أرسل وهو ما بعت. القرارات الحقيقية (مثلاً ربط الفورم بخادم) بتظهر بالملخص.

## بصراحة: شو يعطيك وشو لأ
- **ما بيلاقي أخطاء أكتر من Claude العادي.** بالاختبارات الأعمى (عيوب ما كان يعرفها كاتب السكل) الاثنين لقوا نفس العدد تقريباً.
- **اللي بيضيفه:** إثبات بالمتصفح، تراجع تلقائي، منع الحذف والادّعاءات الكاذبة، ونسخة احتياطية.
- الوضع الكامل (اللجنة): ما انقارن رقمياً بعد. بيضيف آراء من أكتر من زاوية، لكن بكلفة أعلى بكتير.

## المتطلبات
Python 3 وPlaywright وChromium:
`pip install playwright && python3 -m playwright install chromium`
ما في حاجة لمفتاح API. على ويندوز ما انجرّب من الكاتب، فبلّغ عن أي مشكلة.

## ملاحظات
- بيعمل مجلد مخفي `.website-team` جوّا الموقع (فيه النسخة الاحتياطية). **احذفه قبل ما ترفع الموقع.**
- مخصّص للمواقع الثابتة (HTML/CSS/JS). ما بغطي: الأداء، الأمان، متصفحات غير Chromium، خادم حقيقي، روابط خارجية.
